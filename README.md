# One Last Signal
A playable, original NASA Space Apps 2026 mission-design game. Configure a lunar spacecraft, review constraints, operate six lunar orbits, and compare the evidence returned.

## Run
Node 22+, `npm install`, `npm run dev`. Production: `npm run build`, `npm run preview`. Tests: `npm test`.

## Play
Choose payload, antenna, panels, battery, recorder, orbit and delivery service. Review and deploy. Keys 1–4 select Observe / Downlink / Charge / Safe mode; Space pauses. Time rates up to 600×; optional auto operator uses an explicit deterministic policy. Return at least three paired survey cells. Redesign after a mission or export the actual report. Save/load stores designs locally.

## Scope and assumptions
This prototype uses circular lunar orbits and spherical occultation with fixed Earth/Sun directions over six representative orbits. Launch/transfer are contracted and abstracted. Pointing modes model a simplified body-fixed spacecraft with an eight-second slew. Data values are MiB internally (not RF Mbps); batteries use Wh. Packet reception is acknowledged immediately; science credits unique paired proxy/context records. Source constants are factual; costs, components, synthetic readings, footprint and target cells are educational approximations. No real ice detection is claimed. No NASA endorsement.

## AI/SI use
Original game concept: participant, as confirmed by participant. AI assisted source research, technical planning, implementation, tests and debugging. The game has no runtime LLM. Synthetic gameplay records are generated by the documented simulation rather than presented as NASA observations. No AI-generated bitmap/audio assets or modified NASA logos are included.

## Roadmap
